## What this site is

The Amateur Radio License Map plots the locations of licensed amateur radio
operators in the United States. Licence data comes from the FCC's Universal
Licensing System and is refreshed regularly. Addresses are geocoded so each
licensee can be shown on the map.

## How it works

The site is a [Next.js](https://nextjs.org) application. A companion command
line app downloads the FCC data, geocodes the addresses and produces the data
exports. See the [Blog](/blog) for the story of how it was built and what has
changed along the way.

## Data and accuracy

Locations are derived from the mailing address on each licence, which is not
always where the station is actually operated from. Treat the map as a rough
guide rather than a precise record.
