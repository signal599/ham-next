This project continues to serve as a learning tool for me while hopefully providing some usefulness.

I have rewritten the frontend using [Next.js](https://nextjs.org). I’ve been working with Drupal and PHP for many years so this is a new experience for me. Next.js is a combination of [Node.js](http://nodejs.org) on the backend and [React](https://react.dev) on the frontend and lots of magic to make it all work together. The language is [TypeScript](https://www.typescriptlang.org). Most of the backend is still happening in Drupal but I intend to move more of it into Next.js as time permits. A friend named Claude is providing some help along the way. <span class="text-2xl">🙂</span>

I’m sure it’s not perfect so let me know if you find any problems. I can put the old Drupal version back quickly if there are any showstoppers.

The code is still open source [here](https://github.com/signal599/ham-next). It is both an exciting and scary time to be web developer.
