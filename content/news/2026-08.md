The whole site is now Next.js and Node.js written in TypeScript.

It has been recreated and migrated from the old Drupal site which was written in PHP. There are now two applications. [Ham-next](https://github.com/signal599/ham-next) is the Next.js web application that you are looking at now. [HamInfo-cli](https://github.com/signal599/haminfo-cli) is a Node.js cron driven app that handles importing data from the FCC, geocoding and data exports. It’s running on a low cost virtual server at Hetzner. Geocoding uses [Geocodio](https://www.geocod.io) which has a generous free tier. Thank you Geocodio.

It’s been a fun project and learning experience for me. It was mostly hand coded until a couple of months ago when I started using Claude Code. I have found that using Claude has been very successful and a good experience when used carefully.

I'm surprised at how much the site is used. I haven't bothered with any fancy analytics but any time I look at the live web server logs, it only takes a minute or so before I see someone actively using it. Of course there are a lot of bots along with the human visitors.

I think this is about it for now. I've run out of ideas for new features or cleanup. I’m feeling pretty happy with the end result so unless someone has a good idea for an enhancement, I think I'll call it done. It's time to turn my free time attention to something new. That might be a cat game.

Let me know if you find any issues.
