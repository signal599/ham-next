I have migrated from Google Maps to [OpenFreeMap](https://openfreemap.org/). Usage was starting to exceed the free limit on Google Maps. Even though it’s only been two or three dollars per month recently, the scary thing is that Google Maps does not have a way to specify a hard spending limit. It only has a notification when it reaches a certain level. I could get an expensive surprise if something got out of control.

OpenFreeMap is a nice project run by one person. It doesn’t have all the same features but I think it serves the purpose here very nicely. I added a Google Maps link to the station popups which takes you to that location on Google Maps which might be useful if you want to use a Google feature such as Streetview or directions.
